## 📊 必读：数据源真相与高胜率实战用法

### 1. 数据从哪来？需要付费吗？
**完全免费（0 成本），全部直连官方公开信披源**：
1. **深交所「互动易」**（`irm.cninfo.com.cn`）：深市主板（`00`）与创业板（`30`）一手董秘回复。
2. **上交所「上证e互动」**（`sns.sseinfo.com`）：沪市主板（`60`）与科创板（`688`）一手董秘回复。
3. **全景网投资者关系平台**（`ir.p5w.net`）：沪深北（含北交所 `8/92`）全文检索聚合与互补去重。
4. **东方财富股东户数中心 + F10 底层库**：全市场 5500+ 只股票（含 A+B、A+H 股补全）的上期基准与近 30 期历史数据。
5. **东方财富毫秒级实时行情**：实时计算「统计截止日后至今涨跌幅」与实时户均市值。

> **💡 机构买的万元级 Wind / Choice 会有更早的每日股东人数吗？**
> **没有。** A 股股东名册由中登公司独家掌握，只在每月 **10日、20日、月末** 下发给上市公司董秘办，绝不向任何外部机构出售实时接口。付费终端里的旬度户数同样爬自互动易/e互动，但它们多了人工审核入库流程（往往滞后 15 分钟~数小时），而本工具本地直接秒级解析董秘回复并对比上期算出增减（界面标为 **`⚡ 一手抢先`**）。

### 2. 怎么用最有效？（避开“滞后追高坑”）
董秘今天回复的往往是几天前（如上旬 10 日）的截面户数。
- ❌ **错误用法**：只看“股东户数大降 `-10%`”就盲目追买——如果截止日之后这几天股价已经暴涨了 `+25%`，主力很可能已经借拉升出货了。
- ✅ **核心用法**：点击界面上的 **`💎 筹码背离 (户数降·股价滞涨)`** 或选择 **`按黄金潜伏度排序`** —— 专门筛选 **「最新户数明显减少（主力吸筹） + 统计期内横盘未涨 + 统计截止日后到今天现价依然未大涨（≤ 3.5%）」** 的潜伏标的，点开卡片对照双轴趋势图观察是否连续多期集中，胜率远高于只看增减榜。

## ❓ 常见问题（FAQ）

1. **以后代码有新版本，合伙人怎么一键更新？**
   - 如果是用 `git clone` 下载的，在项目目录运行 `git pull`（或直接对 WorkBuddy 说：`帮我执行 git pull 更新最新代码并重启服务`）。
2. **为什么没有声音提醒？**
   - 现代浏览器规定必须先点击过页面才能播放声音，打开网页后随手点一下右上角 **`🔔 测试提醒`**，听到清脆提示音并看到右上角滑出通知卡片即代表声音和弹窗已全部激活。
3. **默认 3688 端口如果被其他软件占用了怎么办？**
   - 无需手动处理，`src/server.mjs` 内置了自动顺延机制（若 `3688` 被占用会自动尝试 `3689` ~ `3697` 并在终端打印实际地址）。
