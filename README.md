# A股实时股东人数监测台 v2.0 (A-Share Real-Time Shareholder Monitor)

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2FTUNAKINGRWA%2Fashare-holder-monitor)

全天候 Web & 移动端实时筹码监测看板，通过 **五引擎并发采集 + 子句级多期语义解析 + 实时跨源真值对账**，精准捕捉沪深京 A 股每旬（10日、20日、月末）最新股东户数变动与筹码集中信号。

- 🌐 **在线云端网页版（GitHub Pages 24h 免开电脑直连）**：https://tunakingrwa.github.io/ashare-holder-monitor/
- ▲ **一键部署全栈 Serverless 版到 Vercel**：https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2FTUNAKINGRWA%2Fashare-holder-monitor

## 核心特性

1. **五引擎全市场并发采集 + 跨源多期时间轴融合**
   - **东方财富股东户数中心 (`RPT_HOLDERNUMLATEST` / `RPT_HOLDERNUM_DET`)**：覆盖沪深京全市场 5500+ 只 A 股，提供上期基准、区间涨跌幅、户均持股市值与 30 期历史序列。
   - **深交所互动易直连 (`irm.cninfo.com.cn`)**：纯时间倒序最新流 + 四关键词（`股东人数` / `股东户数` / `股东总数` / `持有人数`）全口径检索。
   - **上证e互动直连 (`sns.sseinfo.com`)**：实时抓取沪市最新董秘回复流。
   - **全景网投资者关系聚合 (`ir.p5w.net`)**：补齐上证e互动免登录全文关键词检索、北交所及业绩说明会问答，并与直连源智能去重。
   - **毫秒级实时行情引擎 (`push2.eastmoney.com`)**：实时计算 **统计截止日后至今涨跌幅 (`postCutoffChrate`)** 与实时户均持股市值，防止追高“统计日后已爆炒”标的。

2. **高精度语义抽取与实时真值自检 (`100%` 基准集 & 跨源对账)**
   - 支持全角数字、中文数词/日期、中登公司官方表述（`合并普通账户和融资融券信用账户持有人数`、`股份持有人数`、`股东共X户`）、`分别为` 多期并列一对一映射、A+H/B股精准识别。
   - 内置 **防误报护栏**（拦截政企客户/居民用户 `户`、可转债持有人、员工持股/股东大会出席人数、差值前置等）、**旧季报复述自动隔离**、**约数四舍五入误差带提示** 与 **董秘未来日期笔误自动纠偏**。
   - 顶部内置 **`🎯 准确度自检`** 面板：实时展示 **16大类53组黄金对抗基准集评测** 与 **东财官方库跨源真值逐条核验报告**。

3. **后台定时轮询 + 实时提醒 + 高清双轴趋势图**
   - 基于 `SSE (Server-Sent Events)` 毫秒级推送至浏览器，支持自定义轮询间隔、Web Audio 合成双音/三音提示音与 macOS 桌面通知（自动过滤旧季报复述噪音）。
   - 快捷筛选：`筹码集中`、`大幅集中(≤ -5%)`、`急剧集中(≤ -10%)`、`💎 黄金潜伏(筹码降≥2% 且统计期与截止后均未大涨)`、`🚀 一手抢先`、按黄金潜伏度排序。
   - 点击任意股票滑出详情抽屉：查看 **连续集中期数**、**历次股东户数 vs 股价双轴趋势图 + 单期变化率红绿柱** 及全部历史互动问答原文。

## 快速启动

环境要求：Node.js `>= 20`（零第三方依赖，无需 `npm install`）。

### 方式一：命令行启动
```bash
npm start
```
启动后在浏览器打开：`http://127.0.0.1:3688`

### 方式二：macOS 双击启动（内置防休眠与手机公网穿透）
直接双击项目目录下的 [`启动监测看板.command`](./启动监测看板.command)，将自动开启防休眠守护、启动后台服务、建立免注册外网 HTTPS 穿透隧道并打开浏览器。

## 📱 手机端实时看盘（外网 5G + 同 Wi-Fi 双通道）

服务启动后会自动开启双通道访问，点击页面顶部 **`📱 手机看盘`** 按钮即可直接扫码：
1. **外网 5G 随身看（免注册 HTTPS 公网穿透）**：自动通过 `localhost.run` / `Pinggy` 生成 `https://...` 公网加密链接与离线矢量二维码，在外使用 5G 流量或微信扫码即可实时接收 SSE 推送。
2. **家庭/办公同 Wi-Fi 极速直连**：自动识别本机局域网 IP（`http://192.168.x.x:3688`），内网零延迟直连。
3. **全屏原生 App 模式（PWA）**：iPhone Safari 打开后点击底部 **「分享 → 添加到主屏幕」**，即可隐藏地址栏全屏运行，支持手指滑动双轴趋势图十字准星、锁屏唤醒自动重连同步与新披露震动/声音提醒。
